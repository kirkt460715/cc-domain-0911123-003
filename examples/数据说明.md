# 维修站耗材交易

transaction 是一笔领用事务，item 是物料标识，date 是当地业务日期，returned 表示退货。物料为空的记录保留交易身份，便于表示空篮子。相同物料重复出现是原始明细的合法状态，不能假定每行都代表不同交易。

演示把这些记录按现有 DataCatalog 的强类型字段导入受权数据源，导入本身不会计算项集或改变授权。九月和十月可供分析人选择前后窗口。

## 关联分析口径（fixtures/association_demo.json）

- 空交易键（null 或空串）无法归属任何交易，在进入篮子前剔除并单独计数，不参与分母。
- returned=true 的行是退货而不是共同领用，整行剔除；若一笔交易只有退货行，它仍以空篮子保留在选定总体中。
- item 为空的非退货行保留交易身份，形成空篮子；空篮子计入该窗口的交易分母。
- 同一交易内重复出现的物料折叠为一次成员关系，折叠行数单独统计，因此重复明细不会抬高支持度或置信度。
- 发现期（九月）只产生候选：gasket/valve 在发现期置信度为 1、lift 为 4，但验证期（十月）共同交易数为零；验证期不重新挑选规则，只对冻结候选重算指标、单侧 Fisher 检验并对整个候选族做 BH 调整。
- 报告载荷只含聚合规则、四格计数和授权谱系，不含任何交易明细；撤权后同一报告无法继续取回或交付。
